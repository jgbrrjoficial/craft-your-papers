# Craft Your Papers

**Found your nation. Write your laws. Defend your papers.**

A complete nations suite for **Paper & Spigot 1.21+**: territory, governments, economy, diplomacy, standing armies, religions, jobs and live web maps — all in one jar, no dependencies required.

🇧🇷 Made in Brazil by `jg_xines`. MIT licensed — see [LICENSE](LICENSE).

## Features

- 🏳️ Nations, provinces & chunk claims with protection, capitals and banners
- 🗳️ Governments (absolute/council/democracy), elections, referendums, revolutions
- 💰 Physical ore economy (iron/gold/diamond/emerald), inflation, taxes, tributes
- ⚔️ Fair wars (strength ratio), occupations, plunder, fallen capitals, peace treaties
- 🛡️ Guard armies: patrols, garrisons, divisions, training
- 🤝 Diplomacy: war, alliances, NAPs, trade pacts, vassalage
- 🙏 Ideologies & religions, holy wars, faith dividends (disableable)
- 👥 Inhabitant villagers, jobs, payroll, loyalty (desertion & rebellions!)
- 🏢 Ranks, titles, companies, law books
- 🗺️ Live Dynmap / BlueMap / squaremap rendering
- 🔧 `/cyp admin` test cheats (free stuff, no rules)
- 🌍 12 languages · Modes: SIMPLE, ARCADE, REALISTIC, CUSTOM

## Requirements

- Paper or Spigot **1.21.1+** (Paper recommended)
- Java **21**

## Build

```powershell
gradle clean build
```

The jar lands in `build/libs/`. Tests run with the build (121 tests).
